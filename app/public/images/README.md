## 撮り直す場合

本番データは日々更新されるため、提出直前に最新の見た目で撮り直したい場合は、以下の手順で撮影し、同じファイル名で上書きする。

1. Chrome で対象ページ（本番URL、ローカル開発環境のダミーデータは使わない）を開き、`Cmd+Option+I`（Windowsは`Ctrl+Shift+I`）で DevTools を開く。
2. `Cmd+Shift+M`（DevTools 左上のスマホ/タブレットのアイコン）で Device Toolbar を有効化し、幅「1600」・高さ「900」を指定する。
3. `Cmd+Shift+P` でコマンドパレットを開き、「Capture screenshot」と入力して実行する。表示中のビューポートがそのまま PNG として保存される。
