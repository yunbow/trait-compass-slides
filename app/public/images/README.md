# スクリーンショットの置き場所

4枚とも本番サイト（`https://trait-compass.trait-compass.workers.dev`）から取得済みで、`slides.md` から参照されている。

- `result.png` — キャプチャ① 結果画面（30問回答後の領域別レーダーチャート）
- `support-map.png` — キャプチャ② 窓口マッチング地図（台東区・社会人で検索、ピンが複数立つ状態）
- `consent.png` — キャプチャ③ AI解説の送信前プレビュー（「送信されるもの／送信されないもの」の同意ダイアログ。実際に送信はしていない）
- `data-sources.png` — `/data-sources` ページ（スライド③のデータ透明性セクション用）

## 撮り直す場合

本番データは日々更新されるため、提出直前に最新の見た目で撮り直したい場合は、`trait-compass 提出用プレゼン資料...md` §3.6 の手順（Chrome DevTools の Device Toolbar を 1600×900px に設定し「Capture screenshot」）で撮影し、同じファイル名で上書きする。ローカル開発環境のダミーデータではなく本番URLで撮影すること。
